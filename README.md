# BoomYard

A first-person demolition game for phones (iOS and Android, landscape). Each level is a street at sunset full of things to blow up: place a charge, light it, run, and destroy every target before the clock runs out. Unity 6 (URP), built entirely from code, like Overlane. The web build (WebGL) is for testing and demos.

Spec: the artifact **BoomYard Game Spec** (v2.0).

Everything is generated by code, with no external assets: meshes (`MeshKit`), PBR textures (`TextureLib`), materials, explosions, sound and music (`Sfx`). The only files are the two fonts (Rubik and Heebo, OFL).

## What is in it

- **Levels**: a map of 10 levels (`Core/Levels.cs`). Destroy all targets in time; stars by time left. Level 1 is an interactive tutorial.
- **Play**: place an item unlit, walk up and hold LIGHT to light it, then run; or light it in your hand and throw it. Wind, fuse timing, containment ×1.8, chains up to ×6, knockdowns, bonuses.
- **Feel**: layered explosions (flash, HDR fireball, sunlit smoke, dust ring, shockwave, embers, scorch marks, debris), hit-stop, slow motion on chains, camera kick, post-processing punch, vibration.
- **Look**: URP with ACES, bloom, SSAO, colour grading; golden-hour sun and sky, reflections; procedural PBR surfaces and bevelled models.
- **Sound**: synthesised and reverberated firecrackers, explosions (near and far), glass, metal, fire, lighter, fuse, evening ambience, menu music.
- **Menus**: home, level map, shop (explosives, lighters, upgrades), daily missions and a 7-day reward calendar, settings (audio, controls, graphics, accessibility, privacy and terms, reset, credits), pause, results.

## Open in Unity

1. Install **Unity 6000.6.6f1** (the same as Overlane) with Android, iOS and WebGL build support.
2. Clone the repo and **Add project from disk** in Unity Hub.
3. On first open, `Assets/BoomYard/Scenes/Main.unity` and `Assets/BoomYard/Generated` (the URP asset and template materials) are created. Rerun anytime with **BoomYard → Run Project Setup**.
4. Press **Play**. Keyboard and mouse: **WASD** move, **Shift** run, drag to look, **F** (hold) light, **Space** throw (hold for power), **E** place, **1–4** pick an item, **Esc** pause.

## Builds

| Target | How |
|---|---|
| Android | `BoomYard → Build Android`, or `.github/workflows/mobile.yml` (APK, or signed AAB with the upload key in secrets) |
| iOS | `BoomYard → Build iOS (Xcode project)`, then archive in Xcode on a Mac |
| Web | `BoomYard → Build WebGL`; every push to `main` builds and deploys to Vercel (https://boomyard.vercel.app) |

`claude/*` branches run `check.yml`: build, smoke test, and a screenshot timeline pushed to the `screenshots` branch.

Secrets: `UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD`, `VERCEL_TOKEN`. App id: `com.boomyard.game`.

## Layout

| Folder | What |
|---|---|
| `Scripts/Core` | Pure C# rules: catalog, levels, scoring, chains, fuses, wind, round, shop, missions, daily rewards |
| `Scripts/Game` | Game loop, player and hands, explosives, blasts and fire, destructibles, props and the street, rendering, effects, sound, save |
| `Scripts/UI` | HUD and menus (built from code), touch and keyboard controls |
| `Editor` | Project and pipeline setup, command-line builds |
| `Tools/SimTest` | `run.sh` core tests (Mono); `TexturePreview.cs` renders the procedural textures to PNG |
| `Tools/web` | Privacy policy, terms, Vercel headers |
