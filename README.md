# BoomYard

משחק מובייל בגוף ראשון (iOS ו־Android, לרוחב בלבד): עומדים בחצר בלילה, מצית ביד אחת ונפץ ביד השנייה. מדליקים, סופרים, זורקים או מניחים, ובורחים. הנזק נמדד בשקלים. Unity ו־C#, נבנה מקוד כמו Overlane. גרסת דפדפן (WebGL, פרופיל Low) לבדיקות ודמו בלבד.

איפיון מלא: artifact בשם **BoomYard Game Spec** (גרסה 2.0).

**מצב נוכחי (בסיס, M1 מהאיפיון):** זירה 1 (חצר אחורית) עם בית ו־10 חלונות, טרנזיט ישן עם 6 חלקים שעפים, 2 פחים, תא דואר, מזגן, אופניים, משטחי עץ וגדר. ידיים בגוף ראשון עם מצית ופריט, הדלקה (להבה, רוח שמכבה, זמן תפיסה), פתיל בוער עם סרגל אדום/כתום/ירוק לפי מסלול הזריקה, זריקה בכוח משתנה, הנחה ו־Containment (בתוך פח/תא דואר או מתחת לרכב), פיצוצים עם falloff, גל הדף שמנפץ זכוכית, תגובות (פיצוץ משני, הדף, אש, ניפוץ, כיבוי), שרשראות עד ×6, בונוסים, הפלה בגל הדף, סיבוב של 90 שניות ומסך תוצאות. עברית (RTL) ואנגלית, שמירה מקומית, 3 פרופילי איכות.

## פתיחה ב־Unity

1. ב־Unity Hub מתקינים **Unity 6** (‏6000.6.6f1, אותה גרסה כמו Overlane) עם **Android Build Support** ו־**iOS Build Support** (ו־**WebGL Build Support** לבדיקות בדפדפן).
2. משכפלים את המאגר, וב־Hub: ‏**Add → Add project from disk**.
3. בפתיחה הראשונה נוצרת הסצנה `Assets/BoomYard/Scenes/Main.unity` ונפתחת. ההגדרות (לרוחב, Linear, שיידרים) מוחלות אוטומטית; אפשר להריץ שוב מ־**BoomYard → Run Project Setup**.
4. לוחצים **Play**. בעורך ובדפדפן:
   - **WASD**: תנועה, **Shift**: ריצה (ריצה מכבה את המצית)
   - גרירה בעכבר: מבט
   - **F** (החזק): מצית. מחזיקים עד שהפתיל נתפס
   - **רווח**: זריקה (החזקה ארוכה = זריקה חזקה)
   - **E** או קליק על הקרקע / פח / רכב: הנחה
   - **1–4**: בחירת פריט, **Esc**: הפסקה
5. בטלפון: ג׳ויסטיק משמאל (הקשה כפולה = ריצה), גרירה מימין = מבט, 🔥 החזק = מצית, ↑ = זריקה (גרירה למעלה = כוח), הקשה על הקרקע = הנחה.

## בנייה

| יעד | איך |
|---|---|
| Android | ‏`BoomYard → Build Android`, או `.github/workflows/mobile.yml` (APK לבדיקה, או AAB חתום כשיש מפתח בסודות) |
| iOS | ‏`BoomYard → Build iOS (Xcode project)` ואז Archive ב־Xcode על מק, או ה־workflow |
| Web (בדיקות) | ‏`BoomYard → Build WebGL`, ובכל דחיפה ל־`main` נבנה ונפרס ל־Vercel (`.github/workflows/web.yml`) |

סודות נדרשים במאגר (אותם כמו ב־Overlane): `UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD`, ולפריסה `VERCEL_TOKEN`. בלי הסודות ה־workflows מדלגים על הבנייה במקום להיכשל. מזהה האפליקציה: `com.boomyard.game` (ב־`MobileBuild.cs`, קבוע אחרי העלאה ראשונה לחנויות).

## מבנה

| תיקייה | תוכן |
|---|---|
| `Assets/BoomYard/Scripts/Core` | C# טהור בלי Unity: קטלוג (14 פריטים, 28 אובייקטים, 6 זירות, מציתים), ניקוד, שרשראות, פתיל והדלקה, רוח, מצב הסיבוב, כלכלה |
| `Assets/BoomYard/Scripts/Game` | לולאת המשחק, שחקן וידיים, חומרי נפץ, פיצוץ ואש, אובייקטים נהרסים, בניית הזירה, אפקטים, צליל, שמירה, פרופילי איכות |
| `Assets/BoomYard/Scripts/UI` | HUD, מסך פתיחה, תוצאות והפסקה (נבנים מקוד), שליטת מגע ומקלדת, עברית/אנגלית |
| `Assets/BoomYard/Resources` | פונטים (Heebo, Rubik, רישיון OFL) ושיידרים (שמיים, חלקיקים) |
| `Assets/BoomYard/Editor` | הגדרת פרויקט ובנייה מהשורה (WebGL, Android, iOS) |
| `Tools/SimTest` | בדיקות של ה־Core ב־Mono: `Tools/SimTest/run.sh` |

פריט או אובייקט חדש = רשומה חדשה ב־`Catalog.cs`. ערכי הזמן, הנזק והרדיוס הם מהאיפיון.

## השלבים הבאים לפי האיפיון

- **סוף M1:** בדיקה בטלפון של תחושת ההדלקה, הזריקה וההנחה, ושל המצלמה. כיוונון זמני תפיסה, כוח זריקה וגל הדף.
- **M2:** Slow-mo בשרשרת, סרגל Overpressure, התנהגויות מיוחדות (רקטה, עוגה, חבית, Det cord, Thermite), התמוטטות, HUD מלא.
- **M3:** זירות 2–3, חנות ו"החצר שלי" (הסלוטים כבר מסומנים בזירה), כלכלה מלאה, מעבר ל־URP ופרופילי איכות.
- **M4:** זירות 4–6, Remix, יומי, חוזים, Replay/MP4, פרסומות ו־IAP, ארט וסאונד אמיתיים (הידיים, הרכבים, ספריות סאונד).
